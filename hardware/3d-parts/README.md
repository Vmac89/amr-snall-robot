# 3D-printed parts

STL and STEP files for the chassis and other printed parts belong in this folder. None are checked in yet.

When a part is added:

- Export units in millimeters.
- Keep one part per file, with both `.stl` (for slicing) and `.step` (for CAD exchange) when both exist.
- Name files in lowercase with hyphens, for example `chassis-plate.stl` and `chassis-plate.step`.
- Record dimensions from the CAD model or from the printed part. This repository does not yet contain measured chassis dimensions.
